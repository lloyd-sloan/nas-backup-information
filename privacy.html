NAS Work Recovery — Privacy information

This is a private backup tool for its owner's Google accounts. It is not a public backup service and does not accept customer accounts.

Purpose and data used

The tool reads Google Drive file contents and metadata needed to make and verify backups. This can include file names, folder structure, identifiers, sizes, modification times and checksums. Google Docs, Sheets and Slides can be exported to portable file formats. Google account identity is checked to avoid using the wrong account.

Permissions

Recovery connections request read-only Drive access. Separate synchronization or backup-upload connections may request write access only when explicitly authorized by the owner. Google displays the requested permissions before each account grants access. Recovery credentials do not provide editing or deletion permission.

Storage and access

Recovered files, manifests and diagnostic reports are stored on the owner's computers and NAS, and in Google accounts explicitly selected as backup destinations. Credentials are kept separately in private configuration files and are not published on these information pages. Access to stored copies is controlled by the owner. These pages do not contain backup files, access tokens, account inventories or server addresses.

Use and disclosure

The backup scripts use Google data to provide and verify the owner's backups and synchronization. They do not sell data, use it for advertising, or send file contents to AI model training services. Data is transferred between the owner's authorized devices and selected Google accounts as required by those functions. Use of Google API data follows the Google API Services User Data Policy, including its Limited Use requirements.

Retention and revocation

Backup copies and historical versions are retained according to the owner's configured backup policies. Revoking an application's access through Google Account connections stops future authorized access; it does not automatically delete copies already stored. The owner controls restoration, retention and deletion of those copies.

Contact

Use the support address shown on the Google consent screen for this application. This site does not collect support requests or sign-ins.

Website hosting

If published on GitHub Pages, the hosting provider may log visitor IP addresses for security, as described in GitHub's privacy documentation. These pages add no analytics, forms, advertising or tracking scripts.
